# PWA Icons

The following icon files are required for the PWA to work properly:

## Required Icons

1. **icon-192x192.png** - 192x192 pixel PNG icon
2. **icon-512x512.png** - 512x512 pixel PNG icon
3. **apple-touch-icon.png** - 180x180 pixel PNG icon for iOS
4. **favicon.ico** - Standard favicon

## Design Guidelines

- Use the CODE QUEST branding colors (cyan #00d9ff and purple #ff00ff)
- Low-poly aesthetic to match the game style
- Simple, recognizable symbol (e.g., a low-poly sword, crystal, or shield)
- Ensure good visibility at small sizes

## Placeholder Icons

Temporary placeholder icons have been created as SVGs. Replace these with proper PNG icons before production deployment.

## Generation Tools

You can use tools like:
- [Favicon.io](https://favicon.io/)
- [PWA Asset Generator](https://github.com/elegantapp/pwa-asset-generator)
- Design tools like Figma, Illustrator, or Blender for 3D icons
